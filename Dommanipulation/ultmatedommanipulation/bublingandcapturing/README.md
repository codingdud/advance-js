### 🚀 How to Use

1. Open the site (on EPAM network)
2. Click **Add Child** to create nested elements
3. Open **Developer Tools → Console**
4. Click on any element to see event logs

* Enable the **Stop Propagation** checkbox
* Event propagation stops at the clicked element
* Parent elements will not receive the event
